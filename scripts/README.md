# 📜 Scripts

간단한 실행 스크립트입니다.

## 🚀 사용법

### 환경 시작
```bash
./scripts/start.sh
```
MySQL 컨테이너와 레플리케이션을 자동으로 설정합니다.

### 상태 확인
```bash
./scripts/check.sh
```
레플리케이션 상태를 확인합니다.

### 레플리케이션 복구
```bash
./scripts/fix-replication.sh
```
레플리케이션 문제를 해결합니다.

### 환경 정리
```bash
./scripts/stop.sh
```
모든 컨테이너를 중지합니다.
